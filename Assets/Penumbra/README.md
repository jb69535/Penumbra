# Penumbra Assets

Start here when working inside Unity.

- `00_StartHere`: short teammate guide.
- `Scenes`: playable, prototype, and test scenes.
- `Scripts`: C# gameplay and editor code.
- `Prefabs`: reusable scene objects.
- `Data`: ScriptableObjects and designer-editable tuning values.
- `Art`: sprites, animation, materials, tilesets, and visual effects.
- `Audio`: music, sound effects, ambience, and mixers.
- `UI`: menus, HUD, fonts, icons, and UI prefabs.
- `Tests`: Unity edit-mode and play-mode tests.
- `ThirdParty`: manually imported external assets and license notes.

Unity render pipeline settings stay in `Assets/Settings`.
