# Scenes

Put Penumbra Unity scenes here.

- `Prototype_Cave.unity`: current playable prototype scene.
- `Sandboxes/Sandbox_Movement2D.unity`: 2.5D movement, camera, parallax, and hit-motion test scene.

Use clear names for future scenes, such as `CombatTest_Player`, `PuzzleTest_Mirror`, or `Floor01_LowerCave`.
