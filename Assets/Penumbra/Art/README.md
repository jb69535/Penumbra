# Art

Put Penumbra visual assets here: sprites, tilesets, animations, materials, shaders, lighting textures, and VFX.

Create subfolders when content exists, such as `Characters`, `Environment`, `Tilesets`, `Animations`, `Materials`, and `VFX`.

For the current 3D/2.5D direction, use sprites for characters, enemies, and most readable gameplay art, then place them as planes in a 3D scene. Imported images may need Texture Type set to `Sprite (2D and UI)` because the project default behavior mode is 3D. Use Z position, sorting layers, and parallax for depth; use 3D meshes for set dressing and large cave forms when useful.

The prototype builder generates simple placeholder sprites in `Characters`, `Environment`, and `VFX`. Replace those with hand-drawn or hand-painted production art when the movement and puzzle loop feels right.
