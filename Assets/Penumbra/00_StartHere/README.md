# Start Here

Use this folder as the first click inside Unity.

Read these in order:

1. `README.md` at the repository root for setup and collaboration rules.
2. `Docs/GameDesignDocument.md` for the current design.
3. `Docs/ProjectStructure.md` for where each type of work belongs.
4. `Assets/Penumbra/Scenes/Prototype_Cave.unity` to open the current prototype scene.
5. `Tools > Penumbra > Rebuild Prototype Vertical Slice` if the prototype assets need to be regenerated.

Common paths:

- Designers tuning gameplay: `Assets/Penumbra/Data`
- Designers editing visuals: `Assets/Penumbra/Art`
- Developers writing code: `Assets/Penumbra/Scripts`
- Anyone editing reusable objects: `Assets/Penumbra/Prefabs`
