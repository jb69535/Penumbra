# Scripts

Put Penumbra C# code here.

Create subfolders when code exists, such as `Core`, `Camera`, `Player`, `Combat`, `Enemies`, `World`, `Puzzles`, `Data`, `UI`, and `Editor`.

Keep designer-editable values in ScriptableObjects under `Assets/Penumbra/Data` when possible.

For Hollow Knight-style 3D/2.5D scenes, core movement, combat, and hit detection should stay on Unity 2D physics APIs. Camera, parallax, lighting, Z placement, and set dressing create the depth.
