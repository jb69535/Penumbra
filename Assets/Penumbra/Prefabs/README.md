# Prefabs

Put reusable GameObjects here: player, enemies, doors, pickups, hazards, mirror puzzle pieces, cameras, and UI widgets.

Prefer editing a prefab here over duplicating setup across multiple scenes.

`Tools > Penumbra > Rebuild Prototype Vertical Slice` generates the first prototype prefabs here:

- `Player/Wanderer_Player.prefab`
- `Cameras/Camera_Follow2D.prefab`
- `Environment/Block_Greybox.prefab`
- `Enemies/ShadePatroller.prefab`
- `Puzzles/LightSource_Beam.prefab`
- `Puzzles/Mirror_Aimable.prefab`
- `Puzzles/MirrorReceiver.prefab`
- `Puzzles/ReceiverDoor.prefab`
